# Java Banking System

A console-based Banking System developed using Core Java and object-oriented programming concepts.

## Features

- Account creation using Factory Pattern
- Singleton Bank System
- Deposit and withdrawal operations
- Account-to-account transfer
- Transaction history
- Java Streams and Optional
- Strategy Pattern for fee calculation
- Observer Pattern for transaction notifications
- Builder Pattern for loan creation
- Loan calculations and EMI
- File persistence
- Performance monitoring
- Logging
- JUnit tests

## Technologies

- Java
- Maven
- JUnit
- Git
